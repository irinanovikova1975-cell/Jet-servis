# Jet Service — сайт з автооновленням товарів

Сайт більше не тягне товари через сторонні проксі-сервіси прямо в браузері.
Замість цього спеціальний скрипт раз на 15 хв сам заходить у Telegram-канал
(з боку сервера, без CORS) і зберігає товари у файл `products.json`.
Сайт просто читає цей файл. Все безкоштовно.

## Кроки для запуску (один раз)

1. **Створи GitHub-акаунт**, якщо ще немає — https://github.com/signup (безкоштовно).

2. **Створи новий репозиторій**:
   - Натисни "New repository".
   - Назви, наприклад, `jet-service`.
   - Обери **Public** (щоб GitHub Pages і Actions були повністю безкоштовні без лімітів).
   - Створи репозиторій.

3. **Завантаж усі файли з цього проєкту** у репозиторій:
   - На сторінці репозиторію натисни "Add file" → "Upload files".
   - Перетягни туди всі файли й папки: `index.html`, `products.json`, `package.json`,
     папку `scripts/`, папку `.github/` (з файлом workflow всередині).
   - **Важливо**: папка `.github/workflows/update-products.yml` має зберегти свій шлях —
     якщо GitHub запропонує завантажити файли окремо, перевір, що структура папок збереглась.
   - Натисни "Commit changes".

4. **Дозволь Actions самостійно комітити зміни**:
   - Settings → Actions → General → розділ "Workflow permissions".
   - Вибери **"Read and write permissions"** → Save.

5. **Увімкни GitHub Pages**:
   - Settings → Pages.
   - Source: "Deploy from a branch".
   - Branch: `main`, папка `/ (root)` → Save.
   - Через хвилину-дві GitHub покаже посилання виду
     `https://твій-нікнейм.github.io/jet-service/` — це вже готовий сайт.

6. **Запусти оновлення товарів вручну перший раз** (не чекаючи 15 хв):
   - Вкладка "Actions" у репозиторії → "Update products" → "Run workflow".
   - За 10–20 секунд `products.json` заповниться товарами з каналу.

Далі все відбувається само: кожні 15 хвилин GitHub Actions заново читає канал
і оновлює `products.json`. Нічого дублювати вручну не потрібно.

## Якщо захочеш щось змінити

- Назва каналу задана в двох місцях: `scripts/update-products.js` (константа `CHANNEL`)
  і `index.html` (та сама константа) — став однакову назву в обох.
- Частоту оновлення можна змінити в `.github/workflows/update-products.yml`,
  рядок `cron: '*/15 * * * *'` (15 хвилин). Частіше — теж можливо, GitHub Actions
  не гарантує точність до секунди, тому раз на 10–15 хв — оптимально.
